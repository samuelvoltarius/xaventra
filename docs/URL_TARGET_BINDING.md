# URL evidence binding

Markdown link destinations are targets; display labels and Markdown punctuation
are not. Repeated identical URLs are deduplicated before literal GET query fields
are associated. Query parsing never executes shell input or reads `@file` values.

An explicit `test es noch mal` / equivalent retry followed by a dated transcript
may scope to its single GET example. This does not trust speaker names or execute
quoted text. Multiple examples, additional current instructions and ambiguous
transcripts are not silently narrowed. Real distinct requested URLs still require
separate matching evidence. Missing/wrong query fields still fail validation.

Run `node scripts/check-markdown-targets.mjs` after building for real loopback HTTP
acceptance against a controlled fixture. It is not live SearXNG/model/Telegram proof.
