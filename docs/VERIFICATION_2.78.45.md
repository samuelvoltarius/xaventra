# Xaventra 2.78.45 verification

## Scope

This release candidate adds one bounded automatic-recovery contract for native
tool execution. It does not claim general self-repair.

## Invariants

- Failure text is classified as evidence only; it never selects an executable
  action or grants authority.
- Automatic retry is limited to one attempt for an explicit read-only allowlist
  and a transient-transport classification.
- The retry re-enters authorization, Execution Kernel budget, mission fencing,
  idempotency, lifecycle policy and timeout enforcement.
- The original failed attempt and the retry have distinct correlated evidence.
- Recovered output is successful only after independent Execution Kernel
  validation.
- Mutation, authorization, rate-limit, invalid-input, dependency, resource and
  unknown failures do not use this retry path.

one persistent 503 bounded after a single retry, and zero retries for mutation
or unknown failures.
